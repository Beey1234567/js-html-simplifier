# Documentation

This is the non-website documentation for JS-HTML-Simplifier.

## Explanation

The **documentation** will describe what you can do with JS-HTML-Simplifier this includes:

- Functions
- Variables

They will all have detailed descriptions.

## NonWebsite Documentation

This is the Non-Website documentation.

### Functions

Functions are listed here:

ShowHTML()

  Arguments: Elements

This shows every HTML element you specified in the function.

HideHTML()

  Arguments: Elements

  The same as ShowHTML() but it hides the HTML instead

ChangeCSS()

  Arguments: Element, CSS

  Change's the given Element's CSS with the given inline CSS

ColorHTML()

  Arguments: Color, Elements

  Same as HideHTML() but it colors the HTML the given color.

GetHTML()

  Arguments: Value, Method

  Gets the HTML via given method and puts the given Vallue into document

  Current methods:

- id
- class
- name
- tag
- query
- queryall

View function type definitions at **types.d.ts**
